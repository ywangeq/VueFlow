# VueFlow · 音视频工作台

用章节组织文稿与素材，在节点画布中构建、试听、评论、返修和验收音视频。

本项目是独立的媒体工作台，**不是** `@vue-flow/core` 图编辑库。节点舞台复用 scaffold 的 Vue `RelationGraph.vue` 和分层交互，增加深蓝、电蓝与紫色的本地科幻仪表主题，保留第三方来源与许可。

## 当前可用

- 按章节标题或空行拆分整篇文稿；新增章节、修改顺序、正文与独立的表演要求。
- 统一章节图与列表切换；同一节点同时显示旁白、画面及其版本，不再分音频／视频工作区。
- 统一入口导入音视频；同节点共用起点、进度和两条素材轨道预览，按章节连续播放，支持章节／总音量及停顿。
- 评论绑定具体版本与时间点；显式创建局部返修任务，冻结文稿、表演要求、评论和基线版本。
- 导出待执行任务 JSON；外部生成后绑定任务导入，过期结果保留为历史版本，不自动覆盖当前选择。
- 全部音频章节通过审听后，合成导出包含音量和停顿的双声道 WAV。
- 本地工程自动原子落盘、修订冲突检测、未保存草稿恢复入口。

**生成状态如实显示。** 目前生成连接是 `manual-external` 交接模式：创建任务不会调用 MiniMax，也不会扣点。把交接清单交给 Codex，在已授权的 MiniMax 网页或视频工具执行，再导入结果。没有嵌入账户、API Key、自动浏览器或后台执行代理。

旁白与画面当前按章从零点对齐，同时预览。有独立旁白时静音视频原声；没有旁白时播放视频原声。不强制每章同时具备两种素材。当前轨道展示不支持拖动、偏移和裁切。

视频目前支持导入、版本、评论、验收与按章播放；完整视频时间线、字幕、配乐、多轨混合和 MP4 合成导出尚未实现。

## 本地启动

需要 Node.js 22+、pnpm 11+。

```sh
pnpm install
pnpm dev
```

打开 <http://127.0.0.1:5179>。开发服务器与数据 API 都只监听本机。

```sh
pnpm test
pnpm build
pnpm start
```

构建后的本地服务地址为 <http://127.0.0.1:4319>。本任务不部署到公共网络。

## 使用流程

1. 左侧「按章节导入文稿」，或直接编辑开场／正文／结尾。章节标题示例：`# 开场`。
2. 右侧单独编辑朗读正文与表现要求。确认后创建生成任务。
3. 左侧「导出交接清单」交给 Codex 外部生成。也可直接导入已有素材。
4. 在「素材与任务」选择对应待执行任务并导入结果。
5. 「音画与评论」播放、留下时间点评论；点击评论下的重新生成，创建该章的局部返修任务。
6. 调整章节／总音量和停顿，再全文审听。旧版本始终可回选。
7. 解决当前版本的意见并标记通过。完整、当前文稿和表演要求均匹配、无未解决意见的音频可导出 WAV。

## 数据与备份

`data/project.json` 是工程唯一权威来源，`data/media/` 保存音视频，均不提交 Git。界面「工程备份」导出元数据；它不打包媒体，也不是可直接导入的完整备份。完整迁移需要停止服务后复制整个 `data/` 目录。生成账户与私人音色信息不进入仓库。

首版每个运行实例维护一个工程，尚未提供多工程管理。多个标签页保存会做修订检查，不静默覆盖；冲突时可先下载未保存草稿再载入最新工程。

## 技术与边界

- Vue 3 + TypeScript + Vite，原生 HTML 媒体播放、Web Audio 离线混音。
- Node HTTP 本地服务，无数据库和外部运行服务依赖。
- 章节顺序与画布坐标分离；业务状态来源只有工程模型，Canvas 只负责显示。
- 音量范围 0–100%，WAV 导出最长 15 分钟；文件导入上限 256 MiB，浏览器混音单文件上限 150 MiB。
- 后端检查文件签名与轨道标记，浏览器测量时长；不把签名检查当成完整解码验证。
- 支持的具体编码取决于浏览器；常用 WAV、MP3、MP4，另支持部分 FLAC、Ogg、M4A、WebM。

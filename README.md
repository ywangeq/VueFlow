# VueFlow · 音视频工作台

用「工程 → 章节 → 句段」组织文稿与素材，在节点画布中独立生成、试听、评论、返修和验收每个句段的音视频。

本项目是独立的媒体工作台，**不是** `@vue-flow/core` 图编辑库。节点舞台复用 scaffold 的 Vue `RelationGraph.vue` 和分层交互，增加深蓝、电蓝与紫色的本地科幻仪表主题，保留第三方来源与许可。

## 当前可用

- 按章节标题组织整篇文稿，章节内按句子拆成可独立生成的句段；可继续拆分片段，保留原段的素材证据。
- 统一的章节／句段图与列表；同一句段节点同时管理旁白、画面、版本、评论与任务，不分音视频工作区。图配置随工程保存。
- 统一入口导入音视频；同一句段共用起点、进度和两条素材轨道预览，按章节内句段顺序连续播放，支持句段／总音量及停顿。
- 评论绑定具体版本与时间点；显式创建局部返修任务，冻结文稿、表演要求、评论和基线版本。
- 导出待执行任务 JSON；外部生成后绑定任务导入，过期结果保留为历史版本，不自动覆盖当前选择。
- 所有启用句段的音频通过审听后，合成导出包含音量和停顿的双声道 WAV。
- 直接导入 TXT、Markdown、无素材 JSON 工程或包含媒体的 ZIP；默认追加并重新映射 ID，可明确选择采用导入工程的图配置。工程备份导出可恢复的完整 ZIP。
- 本地工程自动原子落盘、修订冲突检测、未保存草稿恢复入口。

**生成状态如实显示。** 目前生成连接是 `manual-external` 交接模式：创建任务不会调用 MiniMax，也不会扣点。把交接清单交给 Codex，在已授权的 MiniMax 网页或视频工具执行，再导入结果。没有嵌入账户、API Key、自动浏览器或后台执行代理。

同一句段的旁白与画面当前从零点对齐，同时预览。有独立旁白时静音视频原声；没有旁白时播放视频原声。不强制每个句段同时具备两种素材。当前轨道展示不支持拖动、偏移和裁切。

视频目前支持导入、版本、评论、验收与按句段播放；完整视频时间线、字幕、配乐、多轨混合和 MP4 合成导出尚未实现。

## 本地启动

需要 Node.js 22+、pnpm 11+。

```sh
pnpm install
pnpm dev
```

打开 <http://127.0.0.1:5179>。开发服务器与数据 API 都只监听本机。

```sh
pnpm test
pnpm build
pnpm start
```

构建后的本地服务地址为 <http://127.0.0.1:4319>。本任务不部署到公共网络。

## 已登记工作流

后续新视频优先选一小章试跑 [章节句段音画构建与审阅](docs/workflows/chapter-segment-media.md)，记录生成、回填、评论返修与连续预览结果，再决定是否扩大使用。MiniMax 官方提供 API，但当前本仓库仍使用网页外部交接；已有本人音色与网页额度能否用于 API 尚未验证。完整入口见 [工作流登记](docs/workflows/README.md)。

## 使用流程

1. 导入整篇文稿或工程文件。标题形成章节，章内句子形成可独立执行的句段；已有工程默认保留并追加。
2. 选择句段，编辑朗读正文与共用的表现／画面要求，再为该句段创建旁白或画面任务。
3. 导出交接清单，交给 Codex 外部生成；也可直接导入已有素材。
4. 选择对应的待执行任务，把结果导入当前句段。
5. 在同一节点预览声音与画面，评论绑定具体素材版本和时间点。返修只处理对应句段、对应媒体。
6. 调整句段音量与停顿，按顺序全文预览。停用句段不参与预览和导出；有待执行任务时需先取消才能停用或删除。
7. 解决当前素材意见并标记通过，导出声音 WAV；需要迁移时下载完整工程 ZIP。

## 数据与备份

`data/project.json` 是工程唯一权威来源，`data/media/` 保存音视频，均不提交 Git。「工程备份」导出包含 `project.json` 与全部被引用媒体的 ZIP，可以通过工程导入恢复到当前实例；默认追加，现有内容不被覆盖。JSON 草稿不含媒体，带有媒体引用时必须使用完整 ZIP，服务不会尝试下载外部 URL。

格式版本为 `schemaVersion: 2`。首次打开旧版工程时，服务先保留原始 `data/project.json.v1.bak`，再原子写入新版。每个旧章节迁移成章节下的一个启用句段，旧执行 ID、素材、评论、验收和任务快照原样保留，不自动拆句。未知未来版本直接拒绝。运行中不要手工覆盖 `data/`；完整目录备份应先停止服务。生成账户与私人音色信息不进入仓库。

首版每个运行实例维护一个工程，尚未提供多工程管理。多个标签页保存会做修订检查，不静默覆盖；冲突时可先下载未保存草稿再载入最新工程。

## 技术与边界

- Vue 3 + TypeScript + Vite，原生 HTML 媒体播放、Web Audio 离线混音。
- Node HTTP 本地服务，无数据库和外部运行服务依赖。
- 章节数组和各章的句段数组决定执行顺序，画布坐标只展示。JSON Schema 与共享格式模块负责工程结构、迁移及文件交换。
- 音量范围 0–100%，WAV 导出最长 15 分钟；文件导入上限 256 MiB，浏览器混音单文件上限 150 MiB。
- 后端检查文件签名与轨道标记，浏览器测量时长；不把签名检查当成完整解码验证。
- 支持的具体编码取决于浏览器；常用 WAV、MP3、MP4，另支持部分 FLAC、Ogg、M4A、WebM。

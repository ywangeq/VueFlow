# 验收

```sh
pnpm test
pnpm build
pnpm dev
```

自动检查覆盖：原子持久化与修订冲突、伪造任务／素材隔离、不可变评论快照、任务去重／取消、文件签名和范围播放、旧正文／表现／基线／评论结果不自动激活、音视频评论边界、验收快照、音量边界、播放所有权、音频解码调度与 WAV、标题解析。

浏览器检查：

- 节点选章与列表选章一致，音视频类型切换状态独立。
- 按标题导入整篇文稿，检查正文保留、章节数量与顺序。
- 创建任务，绑定导入合成测试音，状态从待生成到待试听。
- 播放音频，时间点评论，显式返修创建本地任务。
- 同一章再次导入不会绑定已完成任务；旧任务结果不会覆盖新选择。
- 预览与全文播放互斥，音量与停顿生效；缺段保持可见。
- 验收完整音频并导出可解码 WAV。
- 视频文件真实导入、预览与顺序播放；不把视频预览当成已合成导出。
- 保存并刷新恢复工程；两页修订冲突可下载草稿。
- 桌面与 320／375／414／768px 视口可操作，正文与控件不被覆盖。

真实配音表演和视频完整渲染需要后续接入实际素材／执行器，本次不会以合成测试音冒充验证。

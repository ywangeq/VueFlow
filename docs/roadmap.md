# 音视频构建路线

## 已交付的共同底座

章节、正文／表现、素材版本、时间点评论、验收、任务快照、原版图谱、本地持久化、音视频预览和连播。音频增益与停顿混音导出。

## 下一阶段：真正执行生成任务

在现有任务合同外增加本地 worker 适配器。先对接当前已授权的 MiniMax 网页操作，回传真实进度／失败／扣点证据；再支持其他生成提供者。不能默认改成收费 API。先定义任务领取与取消，防止多 worker 重复付费。

## 视频构建

已有同节点旁白／画面与共同零点预览。后续扩展为统一时间线：章节关联画面、音轨、字幕与画幅，新增视频片段的剪入剪出、字幕校时与配乐混音。渲染作为独立服务适配 Remotion、HyperFrames 或 FFmpeg，工程仍是唯一权威。导出 MP4 前加入真实渲染、抽帧、音画同步与可播放验证。

## 持续使用

多工程列表、媒体随工程可迁移备份／恢复、素材回收与存储监测。保留旧版，清理前检查引用；在线托管与多人权限另行设计。
